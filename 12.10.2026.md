В этом руководстве мы создадим приложение для авторизации пользователя через REST API в локальной сети. 
Приложение будет состоять из одного Activity с одним фрагментом, который отправляет данные для входа (логин и пароль) и получает информацию о пользователе.

## Шаг 0: Создание нового проекта

1. Откройте Android Studio
2. Нажмите "New Project"
3. Выберите шаблон **"Empty Views Activity"**
4. Настройте проект:
   - **Name:** UserAuthApp
   - **Package name:** com.example.userauth
   - **Language:** Kotlin
   - **Minimum SDK:** API 24 (Android 7.0) или выше
5. Нажмите "Finish"

## Шаг 3: Создание API сервиса и Retrofit клиента

Создайте файл `ApiService.kt`:

```kotlin
package com.example.userauth

import retrofit2.http.Body
import retrofit2.http.POST

interface ApiService {
    @POST("api/users/login")
    suspend fun login(@Body request: LoginRequest): UserInfo
}
```

Создайте файл `RetrofitClient.kt`:

```kotlin
package com.example.userauth

import retrofit2.Retrofit
import retrofit2.converter.gson.GsonConverterFactory

object RetrofitClient {
    // ВАЖНО: Базовый URL должен заканчиваться на /
    // Тут пишем внешний ip-адрес компьютера
    private const val BASE_URL = "http://192.168.4.1:5000/"
    
    private val retrofit: Retrofit by lazy {
        Retrofit.Builder()
            .baseUrl(BASE_URL)
            .addConverterFactory(GsonConverterFactory.create())
            .build()
    }
    
    val apiService: ApiService by lazy {
        retrofit.create(ApiService::class.java)
    }
}
```

## Шаг 4: Создание Repository

Создайте файл `UserRepository.kt`:

```kotlin
package com.example.userauth

class UserRepository {
    private val apiService = RetrofitClient.apiService
    
    suspend fun login(login: String, password: String): Result<UserInfo> {
        return try {
            val request = LoginRequest(login, password)
            val userInfo = apiService.login(request)
            Result.success(userInfo)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
}
```

## Шаг 5: Изменение ViewModel для экрана авторизации

Создайте файл `LoginViewModel.kt`:

**Метод 1: Состояния UI (UiState)**
Этот sealed class описывает все возможные состояния интерфейса:
```kotlin
sealed class UiState {
    object Idle : UiState()
    object Loading : UiState()
    data class Success(val userInfo: UserInfo) : UiState()
    data class Error(val message: String) : UiState()
}
```

**Метод 2: Хранилище состояний и функция логина**
Класс ViewModel, который управляет состоянием и вызывает репозиторий:
```kotlin
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.launch

class LoginViewModel : ViewModel() {
    
    private val repository = UserRepository()
    
    private val _uiState = MutableStateFlow<UiState>(UiState.Idle)
    val uiState: StateFlow<UiState> = _uiState
    
    fun login(login: String, password: String) {
        if (login.isBlank() || password.isBlank()) {
            _uiState.value = UiState.Error("Заполните все поля")
            return
        }
        
        viewModelScope.launch {
            _uiState.value = UiState.Loading
            
            repository.login(login, password)
                .onSuccess { userInfo ->
                    _uiState.value = UiState.Success(userInfo)
                }
                .onFailure { exception ->
                    _uiState.value = UiState.Error(
                        exception.message ?: "Ошибка подключения к серверу"
                    )
                }
        }
    }
}
```

```kotlin
private fun initializeViews(view: View) {
    etLogin = view.findViewById(R.id.etLogin)
    etPassword = view.findViewById(R.id.etPassword)
    btnLogin = view.findViewById(R.id.btnLogin)
    progressBar = view.findViewById(R.id.progressBar)
    tvResult = view.findViewById(R.id.tvResult)

```

**Метод 4: Настройка наблюдателей StateFlow**
Этот метод собирает состояния из ViewModel и обновляет UI:
```kotlin
private fun setupObservers() {
    viewLifecycleOwner.lifecycleScope.launch {
        viewModel.uiState.collect { state ->
            when (state) {
                is UiState.Idle -> {
                    progressBar.visibility = View.GONE
                    btnLogin.isEnabled = true
                }
                is UiState.Loading -> {
                    progressBar.visibility = View.VISIBLE
                    btnLogin.isEnabled = false
                    tvResult.text = ""
                }
                is UiState.Success -> {
                    progressBar.visibility = View.GONE
                    btnLogin.isEnabled = true
                    tvResult.text = "Добро пожаловать, ${state.userInfo.name}!"
                    tvResult.setTextColor(android.graphics.Color.GREEN)
                }
                is UiState.Error -> {
                    progressBar.visibility = View.GONE
                    btnLogin.isEnabled = true
                    tvResult.text = "Ошибка: ${state.message}"
                    tvResult.setTextColor(android.graphics.Color.RED)
                }
            }
        }
    }
}
```

**Метод 5: Обработчик нажатия кнопки входа**
```kotlin
private fun setupLoginListener() {
    btnLogin.setOnClickListener {
        val login = etLogin.text.toString()
        val password = etPassword.text.toString()
        viewModel.login(login, password)
    }
}
```

**Замените содержимое метода `onCreateView` вызовом созданных методов:**
```kotlin
override fun onCreateView(
    inflater: LayoutInflater, container: ViewGroup?,
    savedInstanceState: Bundle?
): View? {
    val view = inflater.inflate(R.layout.fragment_login, container, false)
    initializeViews(view)
    setupObservers()
    setupLoginListener()
    return view
}
```

## Шаг 9: Настройка разрешений и сетевого доступа

Откройте `AndroidManifest.xml` и добавьте разрешение на доступ к интернету перед тегом `<application>`:

```xml
<uses-permission android:name="android.permission.INTERNET" />
```

Так как наш сервер работает по протоколу **HTTP** (а не HTTPS), Android по умолчанию блокирует такие соединения. РазрешитеCleartext Traffic, добавив атрибут в тег `<application>`:

```xml
<application
    ...
    android:usesCleartextTraffic="true">
```
